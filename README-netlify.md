# 🌐 Netlify 배포 가이드 — HoneyPot 프롬프트 브릿지

## 이 패키지 구성

| 파일 | 배포 후 역할 |
|---|---|
| `index.html` | 🍯 전체 UI (Netlify에서 호스팅) |
| `netlify/functions/*.mjs` | ⚡ **서버리스 함수 5개** — 키워드 분석·뉴스·WP 발행 처리 |
| `netlify.toml` | 빌드 설정 + API 경로 → 함수 매핑 |
| `proxy.py` / `run.bat` | (선택) 로컬 실행용 대체 브리지 — 배포 사이트에선 불필요 |
| `README.md` / `guide-wordpress-google.md` | 문서 |

---

## 🚀 배포 방법 (Netlify Drop — 1분)

1. **app.netlify.com** 접속 → 무료 가입 (구글/깃헙 계정 OK)
2. **Drag and drop** 영역에 이 **zip 파일**(`honeypot-netlify.zip`)을 그대로 드래그
3. 몇 초 후 배포 완료 → `https://xxxxxx.netlify.app` 주소가 생김

> ⚠️ **zip을 풀지 말고 zip 그대로** 드래그하세요. `netlify/functions/` 폴더 구조가 유지돼야 함수가 인식됩니다.
> Netlify는 zip 안의 `netlify/functions` 폴더를 자동으로 서버리스 함수로 감지합니다.

---

## ✅ 배포 후 — 전 기능이 그냥 동작합니다

이 버전부터는 **로컬 파이썬이 필요 없습니다.** 프록시 로직을 서버리스 함수(JS)로 포팅했기 때문에,
배포된 사이트가 자체적으로 모든 데이터 처리를 합니다:

```
[브라우저] ── https://xxxxxx.netlify.app ──▶ 같은 도메인의 /health, /autocomplete, /news, /wp …
                                                    │ (netlify.toml 리다이렉트)
                                                    ▼
                                           netlify/functions/*.mjs
                                                    │
                                    ┌───────────────┼────────────────┐
                                    ▼               ▼                ▼
                              구글 자동완성    네이버 뉴스      워드프레스 REST API
```

| 기능 | 배포 사이트 (이제) | 비고 |
|---|---|---|
| ① 키워드 분석 (구글 자동완성) | ✅ | 서버리스 함수 |
| ① 토픽 경쟁 (구글 뉴스) | ✅ | 서버리스 함수 |
| ② 프롬프트 생성 | ✅ | 브라우저에서 처리 |
| ③ 역공급 변환·SEO 점검·스키마 | ✅ | 브라우저에서 처리 |
| ③ 🚀 WP 자동 발행 | ✅ | 서버리스 함수 (로컬WP 제외) |

- ⚙️ 설정 탭의 **프록시 주소는 자동으로 같은 도메인으로 설정**됩니다. 건드릴 필요 없어요.
- 상단 상태 칩이 🟢 **"프록시 연결됨"**으로 표시되면 정상입니다.

## 🔌 워드프레스는 어떻게?

- 워드프레스는 **별도 호스팅**(카페24/Hostinger 등)에 설치합니다. Netlify가 WP를 호스팅하는 게 아닙니다.
- 툴이 WP의 REST API(`/wp-json/wp/v2/posts`)로 글을 생성합니다 (애플리케이션 패스워드 사용).
- **로컬 WP(Local by Flywheel 등)는 서버리스 함수에서 접근 불가** — 서버가 인터넷에 없기 때문.
  - 로컬 테스트는 PC에서 `run.bat`/`proxy.py`로 열어서 하세요 (로컬 모드).
  - 실서버 WP(카페24 등)는 배포 사이트에서 바로 발행 가능합니다.

---

## 💻 로컬 모드도 그대로 (선택)

- `index.html`을 **더블클릭(file://)**으로 열면 로컬 모드 → `proxy.py` 실행 필요
- `run.bat` 더블클릭 시 index.html + proxy.py 한 번에 시작
- 두 모드(배포/로컬) 모두 같은 UI와 설정(localStorage)을 공유합니다.

## ⚠️ 참고 사항

- **netlify.app 기본 도메인으로는 애드센스 신청이 안 됩니다** (구글은 독자 도메인 요구).
  작업·연습용으로 쓰고, 본격 운영은 커스텀 도메인(설정 → Domain management) 연결 후 진행하세요.
- 구글 뉴스 RSS는 공식 무료 엔드포인트라 서버 IP에서도 정상 동작합니다.
- Netlify 무료 요금제: 함수 호출 월 125,000회 — 개인 작업용으로 충분합니다.
