# 🍯 HoneyPot 프롬프트 브릿지 — Google-First Edition

**API 비용 0원 · 무료 AI(Gemini 등) + 구글 검색(Google Search) 상단 노출 + 애드센스(AdSense) 수익 최적화** 전용 파이프라인.

> 🎯 방향: **구글 SEO가 1순위.** 네이버식 잡담형·이모지 글쓰기가 아니라, 구글이 좋아하는 정보성·구조적 SEO 가이드 글을 만든다.

```
구글 수요 신호 → 고단가 필터 → 토픽 경쟁도 → 검색 의도 → 꿀통 지수 → E-E-A-T 프롬프트 → 무료 AI → 구글 SEO 발행
```

## 📁 파일 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 전체 UI (단일 파일 — 더블클릭으로 실행, 설치 불필요) |
| `proxy.py` | 로컬 프록시 (Python 3 표준 라이브러리만 사용) |
| `README.md` | 이 문서 |

## 🚀 실행 방법

### 1. index.html 실행
`index.html`을 브라우저로 열면 끝. 프롬프트 생성·역공급 변환·SEO 점검은 **이것만으로도** 동작합니다.

### 2. proxy.py 실행 (권장 — 키워드 분석·뉴스 신호·WP 발행 활성화)
Python 3이 설치되어 있다면:

```bash
python proxy.py
# 🍯 HoneyPot 프록시 서버 시작 → http://127.0.0.1:8787
```

그다음 index.html을 **새로고침** → 상단 상태가 🟢 **프록시 연결됨**으로 바뀌면 완료.

**Windows 사용자**: `run.bat` 더블클릭 → index.html이 열리고 프록시가 같이 시작됩니다.

### 🧪 로컬 워드프레스로 먼저 테스트 (호스팅 전)
- 로컬 WP(Local by Flywheel / XAMPP / Bitnami / Docker)도 REST API가 있어 자동 발행 테스트 가능
- 자체서명 SSL(Local 등)은 **proxy.py가 자동 감지 → 인증서 검증 없이 재시도** (로그에 "자체서명 SSL 감지" 표시)
- 자세한 절차: `guide-wordpress-google.md` → **Phase 2.5**

## 📖 사용 흐름 (Google-First)

### ① 키워드 분석 — 구글 수요 신호
- **구글 자동완성** = 실시간 구글 검색어 수요 신호 (무료·무제한, 프록시 경유)
- 돈 냄새 확장 키워드 자동 생성 (예: `알약` → `알약 다운로드` / `알약 광고 제거`)
- 토픽 경쟁 분석: **구글 뉴스 RSS**(공식 무료) 보도량으로 경쟁 강도 간접 측정
- **🍯 꿀통 지수**(0~100): 검색 의도(거래형 +30) + 고단가 카테고리(보험·대출·법률·병원 +25) + 트리거 단어 + 토픽 경쟁 페널티

> 🔑 무료 키워드 데이터 현실: 구글 키워드 플래너는 구글애즈 계정(광고 캠페인) 필요, API는 유료.
> 무료 전략 = 자동완성(수요) + 구글 뉴스 보도량(경쟁) + 애드센스 실측 RPM → 1~2개월 운영 후 가중치 보정. (④ 구글 세팅 탭에 정리)

### ② 프롬프트 생성 — Google SEO 모드 (2,000자+)
키워드를 넣으면 아래가 결합된 마스터 프롬프트 자동 생성:
- **E-E-A-T 신호**: 경험 문장, 출처 명시, "최종 확인: 2026년 8월" 신선도 문구
- **추천 스니펫 최적화**: 첫 문단 40~60자 직접 답변 지시
- **시맨틱 HTML 구조**: H1 1개 / H2·H3 계층, 표·리스트 활용
- **네이버식 글쓰기 배제 명시**: 이모지 금지, 잡담형·구어체 금지, 첫 문단부터 정보 제공
- 고단가 어휘(LSI) 주입 + 최신 뉴스(팩트 체크) + 내부 링크(앵커 키워드 포함 지시)
- 광고 친화 CTA(3회 이하) + 품질 체크리스트

### ③ 역공급 변환 — 구글 SEO 발행 패키지
AI 글을 붙여넣고 **⚡ 수익 최적화 변환**:
- 마크다운 → 워드프레스용 HTML (H1~H4, 표, 리스트)
- **통합 스키마 JSON-LD @graph**: Article + BreadcrumbList + FAQPage (구글 리치 결과 대상)
- **🔍 구글 SEO 점검**: H1 개수, H2 구조, 키워드 위치, 본문 길이, 테이블, 이미지 alt, 링크, FAQ 감지 → 점수화
- **🦴 사이트맵(sitemap.xml) + 🤖 robots.txt 자동 생성** (서치콘솔 제출용)
- **📰 애드센스 자동 광고 헤더 코드** 생성 (전면·인피드 활성화용)
- 메타 제목/설명 길이 경고(제목 60자·설명 155자), 슬러그 자동 생성
- 광고 삽입 포인트 지정 + WP 예약 발행(REST API, 무료)

### ④ 구글 세팅
- 애드센스 발행자 ID 입력 → 사이트 `<head>` 코드 생성·복사
- 전면(Vignette)·인피드 광고 활성화 가이드
- 서치콘솔 등록·사이트맵 제출·색인 요청 절차 안내
- 무료 키워드 데이터 현실 정리

### ⑤ 설정
- 내부 링크 목록(프롬프트 주입 + 사이트맵 URL로도 사용)
- 인아티클 광고 코드 / WP 애플리케이션 패스워드 / 애드센스 ID

## ⚠️ 반드시 지켜주세요

1. **인간 검수 필수.** AI 생성 글을 대량 발행하면 구글 "스케일 콘텐츠 남용" 정책에 걸려 사이트 전체가 패널티를 받을 수 있습니다. 경험·사실 확인·독자 가치를 반드시 더하세요. **하루 1~2개, 검수 후 발행**이 안전합니다.
2. 금융·법률·의료 키워드는 잘못된 정보 시 법적 책임이 있습니다. 수치와 요건은 공식 소스(정부 사이트, 금융사 공지)로 교차 확인하세요.
3. 자동완성·뉴스 데이터는 로컬 개인 용도로만. 프록시가 요청 간격을 조절하지만, 과도한 배치 크롤링은 하지 마세요.
4. 수요 신호(자동완성)·경쟁 신호(구글 뉴스) 모두 **구글 데이터**만 사용합니다.
5. 스키마를 Yoast/RankMath로 관리 중이면 중복 방지를 위해 플러그인의 FAQ 블록을 사용하세요.
