STEP 1 시드 키워드 입력

수요 신호 = 구글 자동완성(실시간 구글 검색어) · 토픽 경쟁 = 뉴스 보도량

STEP 2 꿀통 지수 분석 결과 (점수순 · 상위 3개 🍯)

🍯 꿀통 지수 산정 기준 보기

토픽 뉴스 10건 이상 (경쟁 신호)-5

TIP 프록시 없이도 되는 것

키워드 분석(구글 자동완성·뉴스 신호)은 프록시가 필요하지만, 돈 냄새 확장 규칙은 브라우저만으로 동작합니다.
예) "알약" → 알약 다운로드, 알약 광고 제거, 알약 무료 설치, 알약 해지 방법… — 거래형·문제해결형 키워드로 자동 변환됩니다.

STEP 3 마스터 프롬프트 생성기 (Google SEO 모드)

키워드를 넣으면 [E-E-A-T + 스니펫 최적화 + H태그 구조 + 고단가 어휘 + 최신 뉴스 + 내부 링크]가 결합된 복사용 프롬프트(2,000자+)가 나옵니다.
네이버식 잡담형·이모지 글쓰기는 금지하도록 프롬프트에 명시되어 있습니다.

💡 생성된 프롬프트를 통째로 복사 → 무료 AI(Gemini 등)에 붙여넣기 → 나온 글을 ③ 탭에 붙여넣으면 끝입니다.

STEP 4 AI 생성 글 붙여넣기 (역공급 변환기)

변환 결과

워드프레스 새 글 → 우측 상단 ⋮ → 코드 편집기 → 전체 붙여넣기 → 블록 편집기 복귀. (또는 커스텀 HTML 블록)

구글 리치리치 결과(FAQ 아코디언·문서 정보)를 위한 JSON-LD @graph (Article + BreadcrumbList + FAQPage).
SEO 플러그인(Yoast/RankMath)이 스키마를 직접 관리한다면 중복 방지를 위해 Yoast/RankMath의 FAQ 블록을 쓰는 것을 권장합니다.

구글 온페이지 점수

    📰 애드센스 세팅 (고단가 수익 활성화)

    애드센스 가입 후 계정 → 계정 정보에서 확인. 없으면 ca-pub-XXXXXXXXXXXXXXXX 자리표시자로 생성됩니다.

    전면(Vignette)·인피드 광고 활성화 방법
    • 애드센스 콘솔 → 광고 → 사이트 전체 광고(자동 광고) → 이 사이트의 자동 광고 켜기
    • 전면 광고: 모바일에서 페이지 전환 시 풀스크린 광고 — 본문이 길고 스크롤이 많을수록 노출↑
    • 인피드 광고: 목록/피드형 콘텐츠 사이 — 카테고리·홈 페이지가 목록형이면 활성화
    • ⚠️ 자동 광고는 본문 밀도·레이아웃에 따라 구글이 알아서 배치합니다. 본문에 인위적 광고 블록을 많이 넣으면 오히려 RPM이 떨어질 수 있습니다.

    🦴 색인 패키지 (Search Console)

    구글 서치콘솔(GSC) 색인 등록 절차
    1. search.google.com/search-console → URL 접두어로 사이트 등록 (예: https://myblog.com)
    2. DNS TXT 레코드 또는 HTML 파일로 소유권 확인
    3. 좌측 사이트맵 → 아래에서 생성한 sitemap.xml 제출
    4. 글 발행 후 URL 검사 → 색인 생성 요청 (신규 사이트는 초기 수 주 소요)
    5. 주의: AI 대량 생성 글을 한꺼번에 쏟아내면 스팸으로 오인될 수 있습니다. 하루 1~2개, 검수 후 발행이 안전합니다.

    💰 무료 키워드 데이터 현실

    • 구글 자동완성 = 실시간 구글 검색어 수요 신호 (이 시스템이 사용, 무료·무제한)
    • 구글 키워드 플래너 = 구글애즈 계정 + 광고 캠페인 필요 (무료 계정으로 월 단위 검색량 일부 열람 가능, API는 유료)
    • 구글 트렌드 = 시계열 인기 비교용 (관련 검색어 자동 API는 토픽 ID 기반이라 키워드 확장에는 부적합)
    • 👉 현실적 무료 전략: 자동완성(수요) + 뉴스 보도량(경쟁) + 애드센스 실측 RPM으로 판단 → 1~2개월 운영 후 실적 데이터로 가중치 보정

    ⚙ 로컬 프록시

    🌐 Netlify 등에 배포된 사이트: 자동으로 같은 도메인의 서버리스 함수를 사용합니다. 이 칸은 건드릴 필요 없어요.
    💻 로컬 파일로 열 때(file://): python proxy.py 실행 필요 (Python 3만 있으면 됨) → 새로고침 → 상단 상태가 🟢 프록시 연결됨으로 바뀝니다.
    직접 만든 원격 프록시(Cloudflare Worker 등)가 있으면 여기에 URL을 넣어도 됩니다.

    🔗 내부 링크 목록 (구글은 내부 링크 구조를 중요시합니다)

    이 목록은 ① 프롬프트의 내부 링크 지시에 주입되고, ② 사이트맵(sitemap.xml) URL 목록으로도 사용됩니다.
    언제 필요한가? 글마다 자동 반영되므로 미리 2~3개만 등록해두면 됩니다. 처음엔 비워도 글은 써집니다.

    💰 광고 코드 (인아티클 광고용)

    빈칸이면 광고 삽입 포인트 주석만 생성됩니다. 자동 광고(전면·인피드)는 ④ 구글 세팅 탭의 헤더 코드로 켭니다.
    언제 필요한가? 애드센스 승인을 받은 후에만! 승인 전에 넣어도 광고가 나오지 않습니다. 지금은 빈칸으로 두세요.

    🚀 워드프레스 (예약 발행용)

    WP 관리자 → 사용자 → 프로필 → 애플리케이션 비밀번호 생성 (워드프레스 5.6+). 비밀번호는 이 브라우저에만 저장됩니다.
    언제 필요한가? 툴의 "🚀 워드프레스 예약 발행" 버튼으로 자동 붙여넣기를 하려면 필수. 일단 수동으로 붙여넣을 거면 비워둬도 됩니다.
    💡 아직 워드프레스가 없다면? 카페24 매니지드 워드프레스(월 450원~) 등으로 먼저 설치하세요 — 자세한 절차는 guide-wordpress-google.md 파일에 있습니다.

    ⚠️ 꼭 읽어주세요 — 이 도구는 "구글 검색 + 애드센스"용 초안 생산 파이프라인입니다. 발행 전 인간 검수가 필수입니다.
    ① 구글 정책: AI 생성 콘텐츠 대량 발행은 "스케일 콘텐츠 남용"으로 간주될 수 있습니다. 경험·검수·사실 확인을 더해 E-E-A-T를 높여야 합니다.
    ② 자동완성·뉴스 데이터는 로컬 개인 용도로만 사용하고, 요청 빈도를 낮게 유지하세요 (프록시가 자동 간격 조절).
    ③ 금융·법률·의료 키워드는 잘못된 정보 시 법적 책임이 따를 수 있습니다. 수치와 요건은 반드시 공식 소스로 교차 확인하세요.
    ④ 네이버 뉴스는 "토픽 경쟁 신호"로만 사용합니다 — 목표는 어디까지나 구글 검색 상단 노출 + 애드센스 수익입니다.
